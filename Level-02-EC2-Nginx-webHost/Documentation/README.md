# 📚 Level 2 - Project Documentation

## 📌 Overview

This folder contains the complete implementation documentation
for the following project:

**Level 2 - Static Website Hosting on AWS EC2 with Nginx**

The project demonstrates how a static HTML/CSS/JavaScript website
was deployed and hosted on an Amazon EC2 instance running
Amazon Linux 2023 using Nginx.
