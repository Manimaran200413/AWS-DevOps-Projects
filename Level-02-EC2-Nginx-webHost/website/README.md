# 🌐 Mustacchio Static Website

## 📌 Overview

This folder contains the complete source code of the static
website used in the **Level 2 - AWS EC2 + Nginx** project.

The website is a multi-page static website built using:

- HTML
- CSS
- JavaScript
- Images
- Fonts

The website was deployed on an Amazon EC2 instance running
Amazon Linux 2023 and served using Nginx.

---

## 🎯 Purpose

The purpose of this website in the Level 2 project is to provide
the application content that is hosted on the EC2 web server.

The main focus of Level 2 is the deployment and hosting process
using:

```text
Amazon EC2
     ↓
Amazon Linux 2023
     ↓
Nginx
     ↓
Static Website
