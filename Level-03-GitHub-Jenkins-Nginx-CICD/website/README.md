# 🌐 Level 3 - Portfolio Website

## 📌 Overview

This folder contains the static portfolio website used in the
**Level 3 - GitHub + Jenkins + Nginx CI/CD** project.

The website is built using:

- HTML5
- CSS3
- JavaScript

The website source code is maintained in GitHub and is deployed
automatically through the Jenkins CI/CD pipeline to an Nginx web
server running on AWS EC2.
